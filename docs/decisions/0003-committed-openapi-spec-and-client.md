# 3. Commit the OpenAPI spec and generate the TypeScript client

Status: accepted

## Context

The routes already declare their contract with `createRoute`, but nothing pins the
shipped API surface: a route change silently moves the contract. API consumers
need a typed client that cannot drift from the server.

## Decision

- `openapi/openapi.json` is the committed contract, exported from the app's `/doc`.
- `openapi/client/` is the typed client, generated by `@hey-api/openapi-ts`.
- `make openapi` regenerates both; `make spec-diff` fails when the committed
  files differ from a fresh generation, and runs inside `make check`.
- The generator needs the classic TypeScript compiler API, so the `typescript5`
  alias (TypeScript 5.9.3) is linked where the generator resolves its peer.
  Remove the alias when the generator supports TypeScript 7.

## Consequences

- Every route change must ship with `make openapi`, or CI fails on `spec-diff`.
- The generated client is self-contained and excluded from lint and duplication gates.
- The OpenAPI document stays version 3.0, the version `@hono/zod-openapi` emits.
