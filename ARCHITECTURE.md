# Architecture

## Overview
High-performance TypeScript backend template powered by Hono, OpenAPI 3.1, Zod 4, Scalar, and Drizzle ORM.

## Directory Structure
- `src/api/routes/`: Route controllers defined with `@hono/zod-openapi`
- `src/core/`: Configuration, database client, and infrastructure
- `src/domain/`: Domain logic, entities, DTO schemas, and services
- `docs/`: Architecture, specifications, plans, and architectural decisions
